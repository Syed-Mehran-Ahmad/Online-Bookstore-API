# Online Bookstore API

A RESTful API built using Node.js, Express.js, and MongoDB Atlas.

## Features
- Add a new book
- Get all books
- Get a book by ID
- Update a book
- Delete a book

## Technologies Used
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- Postman

## API Endpoints

### Get All Books
GET /books

### Get Book By ID
GET /books/:id

### Add Book
POST /books

### Update Book
PUT /books/:id

### Delete Book
DELETE /books/:id
